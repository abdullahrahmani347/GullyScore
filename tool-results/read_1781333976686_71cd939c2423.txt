     1→# GullyScore — Product Requirements Document
     2→## Version 1.0 | June 2026 | Status: Ready for Development
     3→
     4→---
     5→
     6→## 1. EXECUTIVE SUMMARY
     7→
     8→GullyScore is a mobile-first progressive web application for tracking informal cricket matches — gully games, colony tournaments, university grounds, terrace cricket — at a level of fidelity that paper scorecards and WhatsApp groups cannot match.
     9→
    10→**Core thesis:** Every serious gully match eventually produces a score dispute. The current tools are either too casual (manually typing into a group chat) or too complex (full-blown sports management platforms). GullyScore is purpose-built for the middle — fast to start, cricket-accurate in logic, beautiful on a phone screen, and persistent across sessions.
    11→
    12→**Target geography:** South Asia (India, Pakistan, Sri Lanka, Bangladesh) and diaspora communities globally. The app should feel culturally native — names, examples, and aesthetic sensibility should match this context.
    13→

    15→
    16→## 2. PROBLEM STATEMENT
    17→
    18→| Current Solution | Critical Failures |
    19→|-----------------|-------------------|
    20→| Paper scorecard | Disputes, illegible handwriting, water/weather damage, no searchable history, cannot be shared digitally |
    21→| WhatsApp manual updates | Unstructured, tedious, prone to miscounts, no ball-by-ball granularity |
    22→| ESPNcricinfo/Cricbuzz apps | Require registration, designed for broadcast cricket not informal games, overkill UI |
    23→| Generic sports trackers | No cricket-specific scoring rules (extras, strike rotation, over completion) |
    24→| Excel spreadsheets | Completely unusable on mobile, requires expertise to build |
    25→
    26→GullyScore eliminates all five failure modes simultaneously.

   312→#### 6.4.4 Wicket Flow
   313→
   314→On "WICKET" button press → Wicket Modal opens:
   315→
   316→**Step 1 — Dismissal Type:**
   317→Grid of 6 buttons:
   318→- BOWLED (ball → stumps icon)
   319→- CAUGHT (hands icon)
   320→- RUN OUT (running figure icon)
   321→- LBW (leg icon)
   322→- STUMPED (gloves icon)
   323→- HIT WICKET (bat-stumps icon)
   324→- RETIRED HURT (+ icon, rare)
   325→
   326→**Step 2 — Conditional fields based on type:**
   327→- CAUGHT: "Caught by?" → dropdown of fielding team players
   328→- STUMPED: "Stumped by?" → dropdown (usually wicketkeeper, but allow any)
   329→- RUN OUT: "Which batsman out?" → Striker / Non-Striker selector + "Who fielded?" optional dropdown
   330→- BOWLED/LBW/HIT WICKET: No additional info needed
   331→
   332→**Step 3 — Runs on same delivery:**
   333→- Small input: "Runs scored before/during wicket ball?" (default 0)
   334→- This handles: run out where runs were taken, caught where byes were run, etc.
   335→
   336→**Confirmation:** "Confirm Wicket" button → processes ball + opens New Batsman modal
   337→
   338→**New Batsman Modal:**
   339→- Title: "[Dismissed Player] is out. Select new batsman:"
   340→- List of available batsmen (not dismissed, not currently batting)
   341→- Sorted by pre-set batting order
   342→- "Did not bat" indicator for players not yet come in
   343→- Last man: show "Last wicket — innings ends after this batsman"
   344→- If no batsmen left: auto-complete innings

   346→#### 6.4.5 Scoring Logic (Canonical)
   347→
   348→```
   349→DEFINITIONS:
   350→  batsmanRuns  = runs credited to striker (0 for byes/leg-byes)
   351→  extraRuns    = runs to extras column (1 for wide/NB penalty + any bye/LB runs)
   352→  totalRuns    = batsmanRuns + extraRuns
   353→  isLegal      = delivery counts toward the 6-ball over (NOT wide, NOT no-ball)
   354→
   355→BALL RECORDING SEQUENCE:
   356→  1. Insert Ball record (persist immediately)
   357→  2. Update BatsmanInnings (striker):
   358→       balls += (isWide ? 0 : 1)
   359→       runs += batsmanRuns
   360→       fours += (batsmanRuns == 4 ? 1 : 0)
   361→       sixes += (batsmanRuns == 6 ? 1 : 0)
   362→       If isWicket AND dismissedPlayer == striker:
   363→         isOut = true, set dismissalType, bowler, fielder
   364→  3. If RUN_OUT of non-striker: update non-striker BatsmanInnings similarly
   365→  4. Update BowlerInnings (current bowler):
   366→       If isLegal: balls += 1; if balls == 6: completedOvers += 1, balls = 0
   367→       runsAgainstBowler = (isBye || isLegBye) ? 0 : totalRuns
   368→       runs += runsAgainstBowler
   369→       If isWide: wides += 1
   370→       If isNoBall: noBalls += 1
   371→       If isWicket AND wicketType NOT IN [RUN_OUT, RETIRED_HURT]: wickets += 1
   372→  5. Update Innings:
   373→       runs += totalRuns
   374→       wickets += (isWicket ? 1 : 0)
   375→       If isLegal:
   376→         currentBalls += 1
   377→         If currentBalls == 6: completedOvers += 1, currentBalls = 0 (over complete)
   378→       wideBalls += (isWide ? 1 : 0)
   379→       noBalls += (isNoBall ? 1 : 0)
   380→       byes += (isBye ? extraRuns : 0)
   381→       legByes += (isLegBye ? extraRuns : 0)
   382→  6. Strike rotation:
   383→       If isLegal AND batsmanRuns % 2 == 1: swap striker/non-striker
   384→       If isLegal AND currentBalls just became 0 (end of over):
   385→         If batsmanRuns % 2 == 0: swap striker/non-striker
   386→         (If odd: already swapped in step above, non-striker now faces next over ✓)
   387→  7. Check innings completion:
   388→       wickets >= maxWickets → complete
   389→       completedOvers >= totalOvers AND currentBalls == 0 → complete
   390→       inningsNumber == 2 AND runs >= target → complete (chasing team wins)
   391→  8. Return updated state + flags: isOverComplete, needsNewBatsman, needsNewBowler, isInningsComplete
   392→
   393→WICKET ON NO-BALL RULE:
   394→  No-ball dismissals allowed: RUN_OUT only
   395→  All other dismissal types are disabled in the wicket modal when isNoBall=true
   396→  Show notice: "No Ball — only Run Out possible"
   397→
   398→SPECIAL CASE: Wide + Wicket (Stumped or Run Out only off a wide)
   399→  Implementation: Allow STUMPED and RUN_OUT off a wide. Other types disabled.
   400→```
   401→
   402→#### 6.4.6 Undo Last Ball
   403→
   404→```
   405→UNDO SEQUENCE:
   406→  1. Fetch last Ball record for this innings (ordered by deliveryNumber DESC)
   407→  2. If no balls: disable undo button
   408→  3. Reverse BatsmanInnings: subtract runs, balls, fours, sixes. If isOut: restore to active.
   409→  4. If non-striker was run out: restore non-striker too.
   410→  5. Reverse BowlerInnings: subtract runs, balls, over adjustments, wickets.
   411→  6. Reverse Innings: subtract totalRuns, wickets. Reverse over/ball counter.
   412→  7. Restore striker/non-striker to the stored pre-ball strikerId/nonStrikerId in Ball record.
   413→  8. If this was the first ball of a new over: undo also restores previous over state.
   414→  9. If this ball prompted a new batsman selection: remove that batsman from BatsmanInnings.
   415→  10. Delete Ball record.
   416→  11. Re-render UI with restored state.
   417→  12. Show toast: "Last ball undone"
   418→```
   419→
   420→Note: Store strikerId and nonStrikerId BEFORE the delivery in the Ball record to make undo O(1).

   422→#### 6.4.7 Edit Ball
   423→
   424→- Access: long-press any ball in the current over strip, OR "Edit" button in full ball log
   425→- Edit modal: shows ball's recorded values (runs, extras, wicket, batsman, bowler)
   426→- On save: trigger `recalculate(inningsId)` — full recompute of all stats from ball log (O(n) but n is small for gully matches)
   427→- Recalculate function: iterate all Ball records in order, apply scoring logic fresh, overwrite BatsmanInnings, BowlerInnings, Innings totals
   428→- Show loading state during recalculation

   576→### 6.7 Tournament Module
   577→
   578→#### Create Tournament
   579→
   580→**Fields:**
   581→| Field | Detail |
   582→|-------|--------|
   583→| Name | Text, required, e.g., "Colony Premier League" |
   584→| Format | Round Robin (all teams play each other) / Knockout |
   585→| Teams | Multi-select from team list, min 2, max 16 |
   586→| Overs per match | Number input (applies to all matches) |
   587→| Start Date | Date picker |
   588→
   589→**Schedule generation (Round Robin):**
   590→Algorithm: `n*(n-1)/2` matches for n teams. Use round-robin scheduling (Berger tables or rotating pair algorithm). Assign dates sequentially starting from tournament start date.
   591→
   592→#### Points Table
   593→
   594→| # | Team | P | W | L | T | Pts | NRR |
   595→|---|------|---|---|---|---|-----|-----|
   596→| 1 | Colony Strikers | 4 | 3 | 1 | 0 | 6 | +1.250 |
   597→| 2 | Gali Warriors | 4 | 2 | 1 | 1 | 5 | +0.875 |
   598→
   599→**Points:** Win=2, Loss=0, Tie=1
   600→**NRR:** `(∑ runs_scored / ∑ overs_faced) - (∑ runs_conceded / ∑ overs_bowled)`
   601→**Tiebreaker:** NRR (highest wins first), then H2H result.
   602→**Over conversion:** 8.4 overs = 8 + 4/6 = 8.667 decimal overs.
   603→**All-out rule:** If a team is all out before their overs, use their FULL ALLOCATED overs in the NRR denominator (standard in most domestic tournaments).
   604→
   605→**Highlighted row:** Tournament leader gets gold left border. Qualification zone (top 2 for knockout) gets green background.
   606→
   607→#### Tournament Schedule View
   608→
   609→Matches grouped by round. Each match shows:
   610→- Teams + date/time
   611→- Status: UPCOMING / LIVE / COMPLETED
   612→- If completed: scores and result
   613→- If upcoming and both teams exist: "Start Match" button (inline)

  1112→### 9.5 Scoring Screen State Machine
  1113→
  1114→```
  1115→STATES:
  1116→  SETUP_OPENER_1      → Modal: Select striker
  1117→  SETUP_OPENER_2      → Modal: Select non-striker
  1118→  SETUP_OPENING_BOWLER → Modal: Select bowler
  1119→  SCORING             → Main scoring UI
  1120→  PROCESSING          → Buttons disabled, spinner (while API responds)
  1121→  WICKET_MODAL        → Dismissal type + fielder selection
  1122→  NEW_BATSMAN         → Select next batsman
  1123→  OVER_COMPLETE       → Over summary + new bowler selection
  1124→  INNINGS_BREAK       → Innings break screen
  1125→  MATCH_RESULT        → Result screen
  1126→
  1127→TRANSITIONS:
  1128→  SETUP_OPENER_1 → SETUP_OPENER_2 (player selected)
  1129→  SETUP_OPENER_2 → SETUP_OPENING_BOWLER (player selected)
  1130→  SETUP_OPENING_BOWLER → SCORING (bowler selected)
  1131→  SCORING → PROCESSING (button tapped)
  1132→  PROCESSING → SCORING (normal delivery)
  1133→  PROCESSING → WICKET_MODAL (wicket flagged)
  1134→  PROCESSING → OVER_COMPLETE (isOverComplete=true)
  1135→  WICKET_MODAL → NEW_BATSMAN (dismissal confirmed)
  1136→  NEW_BATSMAN → SCORING (new batsman selected)
  1137→  NEW_BATSMAN → OVER_COMPLETE (if over also complete)
  1138→  OVER_COMPLETE → SCORING (new bowler selected)
  1139→  PROCESSING → INNINGS_BREAK (isInningsComplete=true, innings 1)
  1140→  INNINGS_BREAK → SETUP_OPENER_1 (start 2nd innings)
  1141→  PROCESSING → MATCH_RESULT (isMatchComplete=true)
  1142→```
